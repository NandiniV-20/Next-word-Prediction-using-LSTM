 # Next-word-Prediction-using-LSTM
 This project implements a Next Word Prediction model using LSTM (Long Short-Term Memory) neural networks.
The model learns from a text corpus and predicts the most likely next word given an input sequence.

#Tech Stack
- Python 
- TensorFlow  K
- NumPy, Pandas
- NLTK

# Installation usage
- Clone the repository
git clone https://github.com/NandiniV-20/Next-word-Prediction-LSTM.git
cd next-word-lstm

- Install Dependencies
pip install -r requirements.txt
